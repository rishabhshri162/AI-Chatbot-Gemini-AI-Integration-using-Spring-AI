# AI Chatbot – Spring Boot & Google Gemini

An AI-powered chatbot application built using Java, Spring Boot, Spring AI, Google Gemini API and MySQL. The application allows users to interact with Gemini through REST APIs while maintaining persistent conversation history using MySQL.

## 🚀 Features

- **AI Chat Integration:** Generate intelligent responses using Google Gemini.
- **RESTful APIs:** Send messages and receive AI-generated responses.
- **Persistent Chat Memory:** Store conversation messages in MySQL.
- **Conversation Management:** Create and manage multiple conversations.
- **Chat History:** Retrieve previous messages using Conversation ID.
- **Rename Conversation:** Update conversation titles.
- **Delete Conversation:** Delete conversations along with their associated chat history.
- **Conversation Sorting:** Display recently updated conversations first.
- **Input Validation:** Validate incoming API requests.
- **Global Exception Handling:** Handle validation errors centrally.
